# 🎲 Рандомайзер v1.3

Сайт со случайным выбором (12 языков, 8 тем): число (1–2 … 1–1000), страна (193 стран ООН, 2 наблюдателя и 11 частично признанных/непризнанных), политическая идеология (200), сезон и месяц.

Автор: **Zero/Pelmen_4000**

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы из этой папки.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Загружайте файлы прямо в корень, папки не нужны.
4. Через минуту сайт откроется по адресу `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`.

## Файлы для скачивания
- `countries.txt` — список стран
- `ideologies.txt` — список идеологий (рус.), `ideologies_en.txt` — на английском
- `randomizer.py` — консольная версия (Python 3)

Случайность: `crypto.getRandomValues` с отбрасыванием смещения (без перекоса по остатку).
