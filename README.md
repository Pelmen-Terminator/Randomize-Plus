# 🎲 Рандомайзер v1.6

Сайт со случайным выбором: 3 языка (ru, en, es), 8 тем, меню по темам, настройки (количество результатов, исключение повторов).
Числа, страны, профили стран, валюты, годы, идеологии, партии, государства, организации, кино, игры, стили,
имена, фамилии, фэнтези-расы, планеты, сюжеты, еда, жанры музыки, случайный эмодзи, комплименты, знаки зодиака и совместимость, кухни мира, пароли, кубики D&D и свои рандомайзеры.

## GitHub Pages
Загрузите все файлы в корень репозитория → Settings → Pages → `main` / `(root)`.

- `words.txt` — все списки слов в одном файле
- `randomizer.py` — консольная версия (читает `words.txt`)
