# 🎲 Рандомайзер v1.5

Сайт со случайным выбором: 9 языков (ru, en, es, pt, tr, ja, fr, de, it), 8 тем, меню по темам, настройки (количество результатов, исключение повторов).
Числа, страны, профили стран, валюты, годы, идеологии, партии, государства, организации, кино, игры, стили,
имена, фамилии, фэнтези-расы, планеты, сюжеты, еда, жанры музыки, случайный эмодзи, пароли, кубики D&D и свои рандомайзеры.

## GitHub Pages
Загрузите все файлы в корень репозитория → Settings → Pages → `main` / `(root)`.

## Файлы
- `index.html` — сайт
- `words.txt` — все списки слов в одном файле
- `randomizer.py` — консольная версия (читает `words.txt`)
